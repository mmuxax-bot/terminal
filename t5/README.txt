C TERMINAL PRO V2

Quraşdırma:
1. Bütün faylları /ctest/ qovluğuna yükləyin.
2. HTTPS üzərindən açın.

Yeni funksiyalar:
- Premium responsiv mobil və masaüstü dizayn
- GCC və Clang
- Balanced, Strict Debug və Performance profilləri
- İstənilən xüsusi compiler flag
- stdin, compiler və runtime çıxışı
- Avtomatik localStorage yaddaşı
- main.c yükləmə
- Terminal çıxışını kopyalama
- Tam ekran redaktor
- Tab və Ctrl+Enter
- İcranı dayandırma

Təhlükəsizlik:
Kod sayt serverinizdə deyil, uzaq sandbox compiler xidmətində işləyir. Shell girişi verilmir.
İctimai compiler xidmətinin öz resurs və istifadə limitləri ola bilər.
